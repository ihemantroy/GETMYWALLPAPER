# Run this project

Requirements: Node.js 18.18+ (or 20+) and npm.

1. Unzip, open a terminal in this folder.
2. npm install
3. npm run dev
4. Open http://localhost:3000

Your Supabase keys are already in `.env.local`. Build for production with
`npm run build && npm start`. The homepage grid stays empty until you upload
wallpapers at /admin/upload.
